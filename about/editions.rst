Editions and distribution
=========================

|WPf2b| is available through three distribution channels:

Canonical (GitHub)
   The 6.3 open-source release documented in this manual. It provides signed releases, an SBOM, Composer installation, and a self-updater.

WordPress.org (LTS)
   The Plugin Directory distribution. It receives bug fixes and WordPress/PHP compatibility updates on an LTS release line that lags Canonical. Check that distribution's version and use its matching documentation; installing it does not necessarily install the 6.3 Canonical release.

Premium
   The Canonical capabilities plus country blocking, a honeypot, WAF, managed Cloudflare and Jetpack address lists, MaxMind integration, and a structured event history. Premium is distributed through Freemius.

The editions share the syslog, fail2ban, and firewall integration described in :ref:`about_how_it_works`. :ref:`installation_methods` explains how to install the chosen distribution.
