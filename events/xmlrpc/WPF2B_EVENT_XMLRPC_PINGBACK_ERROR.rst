WPF2B_EVENT_XMLRPC_PINGBACK_ERROR
---------------------------------

.. rubric:: Pingback error.

Premium listener: ``WPF2B_EVENT_XMLRPC_PINGBACK_ERROR``.

Premium emits this event when :ref:`WP_FAIL2BAN_LOG_PINGBACKS` is enabled and
WordPress returns an error for ``pingback.ping``. Error code 48 means the
pingback is already registered and does not emit this event.
