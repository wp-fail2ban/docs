About this release
==================

6.3 is the last release whose public configuration story is **QuickStart plus Advanced settings**. The feature model underneath (constants, events, filters) is what 6.4 will keep when policy appears as a first-class UI.

That is why this book is stubborn about names. Cards are not permalinks. The Block / Logging / Remote IPs tabs are not chapters. ``login`` and ``xmlrpc`` exist as internal policy ids in the join file so a later Policy chapter can slot in without rewriting the reference.

If you are reading this after 6.4 ships: the 6.3 manual is still the complete historical 6.3. QuickStart pages remain valid. New work belongs in the 6.4 book and in Life With WPf2b.
