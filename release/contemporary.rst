.. _release_contemporary:

Contemporary versions
=====================

This page records the surrounding software versions at the time WP fail2ban 6.3
is released. It is historical context, not a compatibility or requirements
matrix. The supported PHP minimum for WP fail2ban 6.3 is 8.1; see
:ref:`installation_requirements` for product requirements.

.. admonition:: Release assembly task

   Record the concrete WordPress, PHP, fail2ban, and logging-system versions
   contemporary with the 6.3 release once its release date and final assembly
   environment are fixed. Do not infer a tested or supported range from this
   historical snapshot.
