Contemporary versions
=====================

This manual describes WP fail2ban **6.3**. The Sphinx ``version`` / ``release`` values are filled from the plugin ``package.json`` at build time.

Typical contemporaries at freeze (check the release notes for the exact matrix):

* WordPress current branch at release, plus the LTS flavour’s advertised PHP 7.4 floor
* fail2ban 0.10+ / 1.x with filter.d (or filters.d) support
* syslog-ng, rsyslog, or systemd-journald

OS and panel versions are not listed here; they drift. Life With WPf2b tracks them.
