======
Events
======

An event identifies something |WPf2b| can record, such as a failed login, a
blocked country request, or a WAF detection. Each emitted-event page gives its
message, facility, level, Premium action, and shipped fail2ban filter where
they apply. The reference also lists public event names that exist in 6.3 but
are not currently used.
