.. _feature-waf-sqli:

SQL injection protection
========================

Inspects request data on plugin and/or WordPress paths for SQLi patterns. :ref:`WP_FAIL2BAN_EX_WAF_SQLI_PLUGINS` and :ref:`WP_FAIL2BAN_EX_WAF_SQLI_WORDPRESS` select the surface. ``WAF_ERROR`` is diagnostic.

In 6.3 this is on the Block tab.
