.. _feature-comment-attempts:

Comment attempts
================

Logs attempts to comment on posts that cannot receive comments: missing, closed, trash, draft, password-protected, or an unapproved parent comment. Soft filter. Useful when bots hammer ``wp-comments-post.php``.

The individual control is **Comment attempts** on the Logging tab in Advanced settings.
