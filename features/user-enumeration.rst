User enumeration
================

Blocks the classic ``?author=N`` and REST user-probe patterns so login names cannot be harvested from the site. Each blocked probe is a hard failure. The Username Protection card enables this with :ref:`feature-email-only-login`.

It does not hide author names exposed in feeds, themes, or page content.

The individual control is on the Block tab in Advanced settings.
