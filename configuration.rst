.. _configuration:

=============
Configuration
=============

6.3 has two supported ways to configure the plugin: **QuickStart** (the permanent simple UI) and **Advanced settings** (enable flags, facilities, and lists). Constants in ``wp-config.php`` override both.

The Block / Logging / Remote IPs tabs in Advanced settings are a 6.3 UI layout. They are not the documentation taxonomy — features are.
